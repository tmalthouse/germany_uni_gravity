\section{Market structure}

Following \textcite{HEAD2014131}, the main specification follows the general gravity form
\begin{equation}
F_{odt} = G \, S_o \, M_d \, \phi_{od} \, \eta_{odt},
  \qquad \mathbb{E}\!\left[\eta_{odt} \mid \cdot\right] = 1,
\label{eq:gravity_general}
\end{equation}
with bilateral term
\begin{equation}
\phi_{od} = \mathrm{dist}_{od}^{\,\beta_1}
  \exp\!\Big(
      \beta_2 \mathrm{SameCity}_{od}
      + \beta_3 \mathrm{SameState}_{od}
      + \beta_4 \mathrm{SamePolity}_{od}
    \Big).
\label{eq:phi}
\end{equation}
Origin and destination fixed effects absorb $\ln G + \ln S_o$ and $\ln M_d$, giving estimating equation
\begin{equation}
\begin{split}
\ln \mathbb{E}\!\left[F_{odt} \mid \cdot\right]
  &= \alpha_o + \gamma_d + \beta_1 \ln \mathrm{dist}_{od} \\
  &\quad + \beta_2 \mathrm{SameCity}_{od}
   + \beta_3 \mathrm{SameState}_{od}
   + \beta_4 \mathrm{SamePolity}_{od}.
\end{split}
\label{eq:gravity_baseline}
\end{equation}

``SameState'' indicates whether the origin-destination pair lies within the same sovereign state. ``SamePolity'' indicates whether the origin-destination pair lie within the same province, district, or similar subnational division---this name was chosen because only Prussia had provinces \emph{per se}, but other states had analagous administrative divisions.

In analysis (2) the border effect is split by confessional pairing of origin and university, with the baseline being different-state, different-confession OD pairs, giving estimating equation
\begin{equation}
\begin{split}
\ln \mathbb{E}\!\left[F_{odt} \mid \cdot\right]
  &= \alpha_o + \gamma_d + \beta_1 \ln \mathrm{dist}_{od}
   + \beta_2 \mathrm{SameCity}_{od}
   + \beta_4 \mathrm{SamePolity}_{od} \\
  &\quad + \lambda_{\mathrm{SS,SC}} \mathrm{SS\text{-}SC}_{od}
   + \lambda_{\mathrm{SS,DC}} \mathrm{SS\text{-}DC}_{od}
   + \lambda_{\mathrm{DS,SC}} \mathrm{DS\text{-}SC}_{od}.
\end{split}
\label{eq:gravity_confession}
\end{equation}
Both specifications are estimated using Poisson pseudo-maximum likelihood (PPML), as is standard in this literature, since many origin-destination-year flows are zero.

Note that confession is derived from location, as micro-level confessional data are only available for Heidelberg students. For example, the Prussian Rhineland is a majority-Catholic region in a majority-Protestant state, so students coming from that region attending Berlin would be classified as ``same state, different confession;'' a student from the region attending Freiburg would be classified as ``different state, same confession.'' This is not a perfect metric---many regions had both confessions well-represented, and we know nothing about the behaviour of Jewish students. The appendix presents a robustness exercise looking only at Heidelberg students whose individual religion is known (TODO).

\begin{table}[htbp]
  \ttabbox
  {\caption{Baseline specifications, estimating the structure of the German student market in 1800--50 using a gravity model. Model (1) presents a standard gravity model with a $\log$(distance) term and dummies for same-state and same-polity (essentially same-province) origin-destination pairs. The recovered distance elasticity is similar to the value found in papers studying the modern student market; the very large ``same state'' coefficient indicates that political boundaries were very important in shaping the student market. \\
   Specification (2) decomposes the ``same state'' effect, examining whether it is driven by the state border itself or religious homophily. A student's religion is inferred from the regionally dominant confession (see caveat in text), giving four categories: a student attending a university of the same confession in the same state, same confession in a different state, different confession in the same state, or different confession in a different state. The ``same confession, same state'' category, by far the most common, is omitted. The results of this analysis show that political boundaries are far more determinative of university choice than confession, and that we cannot reject the hypothesis that, within a state, confession has no effect on university choice.}

\end{table}
